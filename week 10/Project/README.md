ESU - Football Records

#### Description:
This project is a personal website that showcases my work, including various football-related content such as winner of last Ballon d'Or winners, FIFA World Cup history, and Champions League records. The website features detailed sections for each topic, with images, text, and tables presenting historical data and achievements in football.

The main goal of this project was to develop a responsive, well-structured website using HTML, CSS, and basic JavaScript. I focused on creating a user-friendly design that effectively displays information while maintaining visual appeal.

### Project Files:

1. **index.html**: This is the homepage of the website. It includes an overview of the main sections of the site, links to other pages, and a basic navigation bar for easy access to the different football-related topics.

2. **Ballon_d'Or.html**: This page is dedicated to the prestigious Ballon d'Or award. It includes a description of the award, historical data, and a table of previous winners along with the year they won.

3. **World-Cup.html**: This page presents the FIFA World Cup, detailing the tournament's history, winners, and other key information. It also features a table listing the World Cup winners and the years they won.

4. **Champions-league.html**: This page highlights the UEFA Champions League, its history, and the teams that have won the prestigious title over the years.

5. **FIFA-Best.html**: This page showcases the FIFA Best Men’s Player Award, presenting a list of winners since its inception.

6. **about.html**: The About Me page introduces the developer, providing a brief personal background and the motivation behind the project.

7. **style.css**: This is the main stylesheet for the website. It includes styling rules for the layout, colors, typography, and responsiveness, ensuring the site looks great on both desktop and mobile devices.

8. **images Folder**: This folder contains all the images used throughout the website, such as the images for Ballon d'Or, World Cup, UEFA Champions League, and FIFA Best.

9. **script.js (Optional)**: This file contains any JavaScript functions (if added) to enhance the interactivity of the website, such as animations or event listeners.

#### Design Choices:
While designing this website, I wanted to ensure that the site was visually appealing and easy to navigate. I chose to use a minimalist design to highlight the content and avoid overwhelming the user with too much information at once. For the layout, I used a simple grid system to keep things organized.

- **Color Scheme**: I opted for a combination of dark and light colors to make the content stand out while providing enough contrast for readability. The About Me section has a black background to create a more professional and serious feel, whereas the other sections have lighter backgrounds to make the content more approachable.

- **Responsive Design**: To ensure that the website is accessible on all devices, I used flexible layouts and media queries. This way, the website adjusts its design based on the screen size of the device, making it mobile-friendly.

#### Technologies Used:
- HTML5
- CSS3
- JavaScript (Optional for interactivity)
- Visual Studio Code (for development)
- GitHub (for version control)

#### Project Motivation:
The inspiration for this project came from my love of football and the desire to create an interactive space where I could share interesting data and content related to football's biggest awards and tournaments. The idea was to combine informative content with an engaging web design that would make users interested in exploring the history of these prestigious football events.
